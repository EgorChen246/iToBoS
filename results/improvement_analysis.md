# Проверка улучшений без переобучения

## Методика

Использованы ранее сохранённые обнаружения на 80 валидационных изображениях (236 объектов). Тестовые изображения не использовались для подбора. Для каждого варианта проверены пороги уверенности 0,01–0,99 с шагом 0,01; критерий — максимальный F1 при IoU сопоставления ≥ 0,5.

Дополнительно проверена NMS с порогами IoU 0,3 / 0,5 / 0,7 / 0,9 и исходный вариант без дополнительной NMS. NMS оставляет наиболее уверенную рамку и удаляет сильно перекрывающиеся. Это может удалять и разные близкие объекты, поэтому автоматически включать её для всех моделей нельзя.

## Результат на валидации

| Модель | Исходный F1 | Лучший F1 с подбором NMS | Изменение FP | Решение |
|---|---:|---:|---:|---|
| YOLO26s | 0,5734 | 0,5734 | без улучшения | оставить исходный вариант |
| Faster R-CNN | 0,5930 | 0,5942 | 127 → 126 | слишком малый эффект для уверенного вывода |
| Deformable DETR | 0,5419 | 0,5459 | 60 → 57 | оставить как опциональный кандидат |

Лучший кандидат DETR: уверенность 0,43, дополнительная NMS IoU 0,3. Precision 64,7% → 65,9%; Recall 46,6% без изменения; MAE количества 1,625 → 1,5875; точное количество 31/80 → 32/80.

Это результат выбора параметров на валидации, не независимое доказательство улучшения. Исходная таблица теста и замеры времени не заменены; скорость варианта с дополнительной NMS заново не измерялась.

## Разбор ошибок исходных вариантов

Категории определены геометрически относительно имеющейся разметки. «Фон» ниже означает только отсутствие достаточного перекрытия с размеченным объектом. Без ручного просмотра нельзя исключить пропущенные в разметке образования.

| Модель | Дубль уже найденного GT (IoU ≥ 0,5) | Неполное перекрытие GT (0,1 ≤ IoU < 0,5) | IoU со всеми GT < 0,1 |
|---|---:|---:|---:|
| YOLO26s | 0 | 6 | 69 |
| Faster R-CNN | 0 | 9 | 118 |
| Deformable DETR | 2 | 6 | 52 |

Основной резерв качества — проверка несовпадающих с разметкой обнаружений и пропущенных объектов, затем работа с данными и обучением. Удаление дублей даёт только небольшой эффект. Дообучение не запускалось, новые изображения не добавлялись.

## Воспроизведение

При наличии исходных данных и сохранённых низкопороговых предсказаний:

```powershell
python tune_postprocessing.py --predictions predictions/deformable_detr_val.json
python main.py evaluate --split val --predictions predictions/deformable_detr_val.json --threshold 0.43 --post-nms-iou 0.3
python -m unittest test_postprocess.py
```

Скрипт подбора разрешает только полную валидационную выборку и обнаружения с порогом сохранения не выше 0,01. Данные и обнаружения локальные, в публичный репозиторий не включены.
